# Contributing to Awesome AI Skills

Thank you for your interest in contributing to this project! We welcome contributions from the community.

## How to Contribute

### Adding New Resources

1. Fork the repository
2. Create a new branch (`git checkout -b feature/new-resource`)
3. Add your resource to the appropriate section in README.md
4. Follow the format: `- **Resource Name** - Brief description with link`
5. Commit your changes (`git commit -m 'Add new resource: Resource Name'`)
6. Push to your branch (`git push origin feature/new-resource`)
7. Open a Pull Request

### Guidelines

- Ensure resources are high-quality and relevant to AI skills
- Provide clear descriptions and working links
- Categorize resources appropriately
- Avoid duplicate entries
- Test all links before submitting

### Code of Conduct

Please note that this project follows a Code of Conduct. By participating, you agree to abide by its terms.

## Questions?

Feel free to open an issue if you have questions or suggestions.

Thank you for helping make this resource better for the AI community! 🚀
